# Student Result Analyzer

A beginner-friendly Python project that collects student names and marks, validates user input, and analyzes student results by categorizing them into passed and failed students.

## Features

- Collects student names and marks from the user.
- Validates student count and names.
- Validates marks within the range of 0–100.
- Categorizes students into Passed and Failed.
- Displays separate lists of passed and failed students.

## Passing Criteria

- Marks greater than or equal to 40: Passed
- Marks below 40: Failed

## Concepts Used

- Python Functions
- While Loops and For Loops
- Conditional Statements
- Lists and Nested Lists
- `break` and `continue`
- `try` and `except`
- Input Validation
- Return Values and Tuple Unpacking

## How to Run

1. Make sure Python is installed.
2. Clone or download this repository.
3. Open the project folder in your terminal.
4. Run the Python file:

```bash
python main.py
```
